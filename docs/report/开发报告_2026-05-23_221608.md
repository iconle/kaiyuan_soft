**根因：**
- `AssessmentService.updateAssessment()` 无条件先删 `assessment_objective` 再写，但 `saveObjectives()` 对空列表直接 return，导致所有绑定丢失

**修复：**
- `updateAssessment()` — 仅当 `objectiveIds != null` 时才删旧写新，传 null 表示不修改绑定
- `handleSubmit()` — 明确构造提交数据，`weightPercent` 显式转 Number，`objectiveIds` 确保为数组
