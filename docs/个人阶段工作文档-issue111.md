## 二、工作背景

在团队协作开发过程中，每位成员需要围绕 GitHub Issue 完成具体功能、问题修复和文档整理，并通过分支、Commit、PR 与 Issue 建立关联，保证开发过程可追溯。

本阶段我的工作主要围绕系统易用性、权限安全性和批量数据维护效率展开。系统原有部分页面操作入口不够直观，部分角色权限不够完善，部分管理功能只能逐条维护数据，在实际使用中效率较低。因此，我结合 Issue 要求，使用 OpenAI Codex 辅助完成了多项功能改进和开发记录整理。

AI 在本阶段主要承担代码阅读、需求拆解、实现思路整理、代码修改建议、错误排查和文档撰写辅助等工作。实际开发过程中，我会先描述需求背景、角色权限、页面位置和验收要求，再让 AI 结合项目代码给出修改方案，最后对生成内容进行检查和调整。
