## Issue 2: 成绩解锁显示异常 + 紧急解锁按钮

**根因：** `unlockApprovedRequest` 在 `courseCalcService.unlockSheet()` 后设置 `status = "UNLOCKED"`，若数据库 ENUM 无此值则抛异常 → 事务回滚 → 成绩单实际未被解锁。

**修复：**
- `UnlockRequestService.unlockApprovedRequest()` — 解锁后状态改为 `APPROVED`（ENUM 安全），先解锁 sheet 再更新 request
- ScoreUnlock.vue「直接解锁」改为「紧急解锁」，仅 ADMIN 可见 + 增强确认提示（说明跳过工单流程的风险）
- 非 ADMIN 看到 LOCKED 行时显示「需管理员操作」提示
