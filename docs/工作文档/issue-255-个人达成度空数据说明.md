# Issue #255 个人达成度空数据说明

## 问题

教师端「个人达成度」页面在尚未完成课程级计算或数据加载失败时，原页面对下一步操作提示不够完整，用户不清楚应先导入成绩、执行课程级计算，还是刷新重试。

## 优化

- 空数据时提示先完成成绩导入和课程级计算。
- 空数据时提供「去课程级计算」入口。
- 搜索无结果时保留「清空搜索条件」入口。
- 数据加载失败时显示失败原因，并提供「重新加载」入口。
- 导出按钮禁用时增加原因提示，避免用户误以为按钮故障。
- 导出函数增加兜底校验，避免空数据时继续请求导出接口。

## 验证

1. 未完成课程级计算时进入「个人达成度」页面，应看到空数据说明和「去课程级计算」入口。
2. 输入不存在的学号或姓名，应提示未找到匹配学生，并可清空搜索条件。
3. 网络异常或服务异常时，应显示加载失败提示，并可点击「重新加载」。
4. 没有个人达成度数据时，导出按钮应禁用并说明原因。
5. 完成课程级计算后，页面应正常展示学生个人达成度列表。
