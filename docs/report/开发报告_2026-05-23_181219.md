## 需求

主讲教师提交勘误申请后，应能查看申请状态并可撤销；教务/管理员审查后批准（解锁）或拒绝；教师端同步看到状态变更。

## 实现

### 勘误工单状态流转

```
教师提交 → PENDING（待审批）
               ├── 教务/管理员批准 → UNLOCKED（已解锁，成绩单解锁，教师可修改）
               └── 教务/管理员拒绝 → REJECTED（已拒绝）

教师可随时：PENDING 状态 → 撤销（删除工单）
```

### 后端变更

| 文件 | 变更 |
|------|------|
| `UnlockRequestService.java` | 新增 `getRequestsByClass()`（教师查自己的申请）、`cancelRequest()`（教师撤销）；`approveRequest()` 状态改为 UNLOCKED |
| `ScoreController.java` | 新增 `GET /api/classes/{classId}/my-unlock-requests` + `POST .../cancel-unlock-request/{id}` |
| `migrate_unlock_request.sql` | ENUM 增加 UNLOCKED 值 |

### 前端变更

| 文件 | 变更 |
|------|------|
| `CourseCompute.vue` | 新增「我的勘误申请」卡片：显示工单列表（原因/时间/状态/撤销按钮）；LOCKED 时若已有 PENDING 申请则隐藏「提交勘误申请」按钮；提交后自动刷新申请列表 |
| `ScoreUnlock.vue` | 状态标签更新：PENDING=待审批/UNLOCKED=已解锁/APPROVED=已同意/REJECTED=已拒绝 |

### 教师视角状态同步

- PENDING → 黄色「待审批」+ 可点击「撤销」
- APPROVED → 蓝色「已同意」
- UNLOCKED → 绿色「已解锁」（成绩已可修改）
- REJECTED → 红色「已拒绝」
