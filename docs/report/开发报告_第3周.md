## 4. 计算引擎实现要点

### 4.1 三级计算隔离设计

```java
// 第一级：纯函数，输入 → 输出，无副作用
Level1Calculator.calcObjectiveAchievement(scores, objectiveId, assessmentMap);

// 第二级：纯函数，含权重归一化校验
Level2Calculator.calcCourseAchievement(objAchievements, weightRecords);

// 第三级：纯函数，含宏观权重归一化校验
Level3Calculator.calcMajorAchievement(courseAchievements, macroWeights);
```

所有计算器为纯静态方法，由 Service 层（CourseCalcService / GlobalCalcService）负责事务编排和数据持久化。

### 4.2 事务安全

- **阶段一（课程级计算）**：`@Transactional(rollbackFor = Exception.class)` 包裹整个流程（校验 → Level1 → Level2 → 持久化 → 锁定），确保原子性
- **阶段二（专业级计算）**：同上，额外使用乐观状态检查防止并发重复计算
- **解锁流程**：删除已有计算结果 + 状态回退在同一事务中完成

### 4.3 权重校验

- 容差机制：允许 0.01 以内的浮点误差
- 校验时机：计算触发前（而非配置时），双重保障
- 错误消息明确指向具体指标点ID和总和值
