### 2.4 关键业务逻辑

**权重归一化校验（A-4 / B-2 共用机制）：**

```
按指标点 k 分组 → 累加所有权重 → |sum - 1.0| < 0.01 ?
  通过 → 保存
  不通过 → 抛出 BizException，返回具体哪个指标点不满足
```

**大纲自动创建：** 教师首次操作课程目标/考核点时，系统自动创建 `course_outline`（status=DRAFT），无需手动初始化。

### 3.3 路由与布局更新

- 路由新增 7 个页面路由，按角色分组
- AdminLayout 改为根据用户角色动态显示菜单组（系统管理/教务管理/专业管理/课程大纲）
- 所有新路由均配置 `meta.roles` 进行权限守卫

### 3.4 宏观支撑矩阵页面特性

- 动态列数（根据指标点数量）
- 每个单元格为 `el-input-number`，支持精确到 0.0001
- 底部显示列合计，绿色=通过（≈1.00），红色=不通过
- 全部通过时才允许提交
- 支持添加新的课程支撑关系（多选指标点）
