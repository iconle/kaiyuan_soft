# Issue #271 个人达成度返回课程级计算入口

## 问题

教师端「个人达成度」页面用于查看学生个人达成度，但用户如果想返回课程级计算页面查看课程目标或指标点达成度，需要自行从侧边栏切换，流程不够顺畅。

## 优化

- 页面顶部增加「返回课程级计算」按钮。
- 点击后跳转到当前所选教学班级的课程级计算页面。
- 空数据提示区域也保留返回课程级计算入口，方便用户回到课程级计算页面执行计算。
- 按钮增加 tooltip，说明可返回查看课程目标、指标点达成度和计算结果。
- 移动端下页头按钮可换行展示，避免遮挡导出按钮。
- 不影响现有导出 Excel 和查看详情功能。

## 验证

1. 进入教师端「个人达成度」页面，页头应显示「返回课程级计算」按钮。
2. 点击按钮后，应跳转到当前所选教学班级的课程级计算页面。
3. 当个人达成度暂无数据时，空数据提示区仍应显示返回课程级计算入口。
4. 导出 Excel 和查看详情功能应保持可用。
5. 窄屏下页头按钮不应遮挡页面标题或导出按钮。
