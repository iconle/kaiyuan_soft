# Issue #270 课程级计算返回成绩导入入口

## 问题

教师端「课程级计算」页面在成绩未导入或需要修改成绩时，只显示文字提示，用户需要自行从侧边栏返回「成绩导入」页面，流程不够连贯。

## 优化

- 成绩未导入时，在提示区域显示「去成绩导入」按钮。
- 成绩已导入但尚未计算时，显示「查看或修改成绩」按钮。
- 页面增加前置操作条，明确下一步应先导入、核对或修改成绩。
- 点击入口后跳转到当前教学班级的成绩导入页面。
- 已锁定状态下不展示返回成绩导入入口，避免破坏勘误申请流程。
- 入口在窄屏下保持可读。

## 验证

1. 未导入成绩时进入「课程级计算」页面，应看到「去成绩导入」入口。
2. 点击入口后，应跳转到当前教学班级的成绩导入页面。
3. 成绩已导入但未计算时，应看到「查看或修改成绩」入口。
4. 点击入口后，应跳转到当前教学班级的成绩导入页面。
5. 成绩单锁定后，应保持现有勘误申请入口，不展示返回成绩导入入口。
