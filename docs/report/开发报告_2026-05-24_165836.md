## 问题

指标 3 的手工验算值（0.8304）与系统值（0.8241）存在 0.0063 微小差异。

## 根因

归一化在课程级权重上执行（ΣW_c 按课程求和），然后拆分到班级。浮点累加路径不同导致微小偏差。

## 修复

重构归一化顺序：**先拆分到班级，再按班级级 Σ 归一化**。

```
旧：课程级 ΣW_c → 归一化 → 拆分到班级
新：拆分到班级 → 班级级 ΣW → 归一化
```

`rawWeights` 先按班级数均分（不做归一化），计算 `perClassSums`（所有班级权重和），再对每条班级权重乘归一化因子。确保最终 ΣW（跨所有班级）= 1.0。
