# Issue #269 成绩导入后进入课程级计算入口

## 问题

教师端「成绩导入」页面在成绩导入成功或手动保存成绩修改后，用户需要自行从侧边栏进入「课程级计算」页面，流程不够连贯。

## 优化

- 成绩导入成功后显示「去课程级计算」入口。
- 手动保存成绩修改成功后显示「去课程级计算」入口。
- 部分成绩保存成功时也保留入口，同时继续提示失败数量。
- 点击入口后跳转到当前教学班级的课程级计算页面。
- 成功提示中补充“可继续进行课程级计算”。
- 已锁定状态下不展示该入口，保持原有勘误申请流程。

## 验证

1. 在「成绩导入」页面上传成绩模板并导入成功。
2. 页面应出现「去课程级计算」入口。
3. 点击入口后，应跳转到当前教学班级的课程级计算页面。
4. 手动修改成绩并保存成功后，也应出现该入口。
5. 成绩单锁定后，页面仍应保持原有勘误申请提示，不展示该入口。
