## 一、修复的问题

### 1.1 教务管理员移除学生功能不生效

**问题描述：**
- 位置：`/academic/teaching-classes` 教学班级管理 → 管理学生 → 已分配学生 → 移除按钮
- 现象：点击"移除"按钮后，前端显示"已移除"，但实际数据库中学生并未被移除
- 影响：教务管理员无法从教学班级中移除学生

**根本原因：**
MyBatis-Plus 配置文件中启用了逻辑删除 (`logic-delete-field: deleted`)，但数据库表 `class_student` 和 `ClassStudent` 实体类中都没有 `deleted` 字段。这导致 `delete()` 方法尝试执行逻辑删除（将 `deleted` 字段设为 1）而不是物理删除，但由于字段不存在，删除操作实际未生效。

**修复内容：**

| 文件 | 修改内容 |
|:-----|:--------|
| `backend/src/main/resources/application.yml` | 移除 `logic-delete-field: deleted` 配置 |
| `backend/src/main/java/com/obe/platform/modulea/service/DictService.java` | 添加删除结果校验，影响0行时抛出异常 |

**修改前配置：**
```yaml
mybatis-plus:
  global-config:
    db-config:
      logic-delete-field: deleted  # 移除此行
```

**修改后方法：**
```java
@Transactional
public void removeClassStudent(Long classId, Long studentId) {
    int rows = classStudentMapper.delete(
            new LambdaQueryWrapper<ClassStudent>()
                    .eq(ClassStudent::getClassId, classId)
                    .eq(ClassStudent::getStudentId, studentId));
    if (rows == 0) {
        throw new BizException("移除失败：学生不在该教学班级中或已被移除");
    }
}
```

**验证方式：**
重启后端服务，以教务管理员身份登录，进入教学班级管理，点击"管理学生"，选择已分配学生标签页，点击"移除"按钮，确认学生被成功移除。

## 二、新增的功能优化

### 2.1 指标点编号自动生成

**需求背景：**
- 原有功能：新增指标点时需要手动输入编号（如 3-1、3-2）
- 存在问题：用户容易输入错误编号，或忘记当前最大编号导致重复
- 优化目标：编号自动生成，减少用户操作，避免编号冲突

**修改内容：**

#### 2.1.1 前端修改

**文件：** `frontend/src/views/director/GradReqManage.vue`

**修改前：**
```html
<el-form-item label="编号" required>
  <el-input v-model="indicatorForm.indicatorNo" placeholder="如 3-1" />
</el-form-item>
```

**修改后：**
```html
<el-form-item label="编号">
  <el-tag v-if="!editingIndicator" type="info">自动生成</el-tag>
  <el-tag v-else type="info">{{ indicatorForm.indicatorNo }}</el-tag>
</el-form-item>
```

#### 2.1.2 后端修改

**文件：** `backend/src/main/java/com/obe/platform/modulea/service/GradReqService.java`

新增方法：
```java
/**
 * 生成下一个指标点编号
 * 格式：毕业要求编号-序号，如 3-1, 3-2, 3-3...
 */
private String generateNextIndicatorNo(Long gradReqId, Integer reqNo) {
    List<Indicator> existing = indicatorMapper.selectList(
            new LambdaQueryWrapper<Indicator>()
                    .eq(Indicator::getGradReqId, gradReqId));

    int maxSeq = 0;
    for (Indicator ind : existing) {
        String no = ind.getIndicatorNo();
        if (no != null && no.startsWith(reqNo + "-")) {
            try {
                String seqStr = no.substring((reqNo + "-").length());
                int seq = Integer.parseInt(seqStr);
                if (seq > maxSeq) {
                    maxSeq = seq;
                }
            } catch (NumberFormatException ignored) {
                // 忽略格式不正确的编号
            }
        }
    }
    return reqNo + "-" + (maxSeq + 1);
}
```

修改 `addIndicator` 方法，调用自动生成：
```java
@Transactional
public void addIndicator(Long gradReqId, Indicator indicator) {
    GradRequirement existing = gradRequirementMapper.selectById(gradReqId);
    if (existing == null) {
        throw new BizException("毕业要求不存在");
    }
    indicator.setGradReqId(gradReqId);

    // 自动生成指标点编号
    if (indicator.getIndicatorNo() == null || indicator.getIndicatorNo().isBlank()) {
        indicator.setIndicatorNo(generateNextIndicatorNo(gradReqId, existing.getReqNo()));
    }

    indicatorMapper.insert(indicator);
}
```

**无需修改数据库表结构。**

- 移除了 MyBatis-Plus 的逻辑删除配置
