## Bug 1: CourseCompute.vue 模板编译错误

**现象：** `v-else/v-else-if has no adjacent v-if or v-else-if`

**根因：** `<el-dialog>` 元素插入在 `v-if` 和 `v-else-if` 之间，打破了 Vue 条件链。Vue 要求 `v-if`/`v-else-if`/`v-else` 必须是相邻的兄弟元素。

```html
<!-- 修复前 -->
<el-alert v-if="status === 'LOCKED'"> ... </el-alert>
<el-dialog> ... </el-dialog>                          ← 打断了条件链！
<el-alert v-else-if="status === 'IMPORTED'"> ... </el-alert>
<el-alert v-else> ... </el-alert>
```

**修复：** 将 `<el-dialog>` 移到 `v-if`/`v-else-if`/`v-else` 条件链之后。

## Bug 2: 成绩解锁页面 500 错误

**现象：** 管理员和教务管理员点击成绩解锁均提示服务器内部错误

**根因（1）：** ScoreUnlock.vue 调用 `/api/admin/unlock-requests` 查询 `score_unlock_request` 表，该表由 `migrate_unlock_request.sql` 创建，若未执行迁移则表不存在导致 SQL 异常。

**根因（2）：** 重写 AdminScoreController 时丢失了旧的 `POST /api/admin/scores/{sheetId}/unlock` 直接解锁端点。

**修复：**
1. ScoreUnlock.vue 改为双 Tab 设计：
   - Tab 1「成绩单状态」— 展示所有 score_sheet，支持直接解锁（无需工单表）
   - Tab 2「勘误申请」— 展示 unlock_request 工单，含异常捕获（表不存在时显示迁移提示）
2. AdminScoreController 恢复 `POST /scores/{sheetId}/unlock` 直接解锁端点
3. 注入 CourseCalcService 到 AdminScoreController
