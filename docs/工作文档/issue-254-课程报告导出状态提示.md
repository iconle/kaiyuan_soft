# Issue #254 课程报告导出状态提示

## 问题

教师端课程级计算页面的报告导出依赖成绩导入和课程级计算结果。此前在未满足导出条件时，页面缺少明确提示，用户不清楚应该先完成哪一步。

## 优化

- 导出按钮区常驻展示，方便用户明确报告导出入口。
- 未导入成绩时，提示先进入「成绩导入」页面导入成绩。
- 已导入成绩但未计算时，提示先点击「一键计算」生成达成度结果。
- 成绩单已锁定但暂未读取到结果时，提示刷新或重新进入页面。
- 导出请求增加前置校验和失败提示，避免只显示笼统错误。

## 验证

1. 未导入成绩时进入「课程级计算」页面，导出按钮应禁用，并提示先导入成绩。
2. 页面状态标签为「已导入」时，导出按钮应禁用，并提示先执行课程级计算。
3. 点击「一键计算」完成后，导出按钮应可用。
4. 分别点击 PDF、Excel、学生个人达成度导出，应出现开始下载提示。
