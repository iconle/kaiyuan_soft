## 问题

管理员对 APPROVED 状态的勘误申请点击「解锁」时，提示"服务器内部错误"。

## 根因分析

**主要原因：** `score_unlock_request` 表 ENUM 列缺少 `UNLOCKED` 值。

`unlockApprovedRequest()` 执行 `req.setStatus("UNLOCKED")` 后调用 `requestMapper.updateById(req)`，MySQL 因 ENUM 中没有 `UNLOCKED` 抛出 `DataTruncationException` → 500。

**次要加固：**
- `unlockApprovedRequest()` 增加前置校验：解锁前检查 sheet 是否仍为 LOCKED 状态，避免重复解锁
- `GlobalExceptionHandler` 通用异常处理附加实际错误消息，方便排查

## 修复文件

| 文件 | 变更 |
|------|------|
| `docs/database/fix_unlock_request_enum.sql` | 新增：ALTER TABLE 增加 UNLOCKED 到 ENUM |
| `UnlockRequestService.java` | `unlockApprovedRequest` 增加 sheet 状态前置校验 |
| `GlobalExceptionHandler.java` | 500 响应附加 exception message |
