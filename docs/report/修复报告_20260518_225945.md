## 一、支撑矩阵模块点击无响应 — 分析与修复

### 问题描述

以专业负责人（DIRECTOR）身份登录后，点击左侧菜单「专业管理 > 支撑矩阵」，页面无任何响应，不跳转也不加载组件。

### 根因分析

**文件**: `frontend/src/views/director/MacroMatrix.vue:83`

```js
// 错误的导入路径
import { listMajors, listCourses } from '../../api/admin'
```

`listCourses` 函数实际定义在 `frontend/src/api/academic.js`，而非 `frontend/src/api/admin.js`。`MacroMatrix.vue` 作为懒加载组件（router 中使用动态 `import()`），当 Vite 尝试解析该模块时，`listCourses` 在 `admin.js` 中不存在，导致模块加载失败。路由虽然被触发，但目标组件无法挂载，表现为点击后「无反应」。

### 修复内容

**修改 1** — `frontend/src/views/director/MacroMatrix.vue:83-84`

将错误的合并导入拆分为两个独立导入，从正确路径引入 `listCourses`：

```js
// 修复后
import { listMajors } from '../../api/admin'
import { listCourses } from '../../api/academic'
```

**修改 2** — `frontend/src/layouts/AdminLayout.vue:53`（附带问题）

侧边栏所有图标组件（Setting、User、Collection、School 等共 13 个图标）在模板中使用但未在 `<script setup>` 中导入，Vue 运行时会持续输出组件解析警告。已补全导入：

```js
import { Setting, User, Collection, School, Notebook, UserFilled,
         DataAnalysis, Document, Grid, EditPen, Aim, Scale, List }
  from '@element-plus/icons-vue'
```

### 影响范围

- 仅修改导入语句，不涉及业务逻辑变更
- 不影响其他模块

## 二、测试数据补充

### 背景

当前 `docs/database/seed_test_data.sql` 已覆盖模块 A（权限字典、培养方案、宏观矩阵、教学班级、学生）的测试数据，但模块 B（课程大纲、课程目标、内部权重、考核点）及成绩模块均无数据，导致「课程目标设定」「权重分配」「考核点映射」等教师端页面打开后为空。

### 新增脚本

**文件**: `docs/database/seed_module_b_test_data.sql`

执行顺序: `init.sql` → `seed_test_data.sql` → `seed_module_b_test_data.sql`

### 数据内容概览

| 表 | 记录数 | 说明 |
|---|---|---|
| `course_outline` | 3 | 数据结构、C语言、计算机网络各1个大纲 |
| `course_objective` | 9 | 数据结构4个、C语言3个、计算机网络2个 |
| `objective_indicator_weight` | 14 | 课程目标到指标点的内部贡献权重 |
| `assessment_point` | 11 | 数据结构5个、C语言3个、计算机网络3个，各课程总分100 |
| `score_sheet` | 3 | 数据结构的成绩单状态为 IMPORTED，其余为 EMPTY |
| `student_score` | 100 | 数据结构班20名学生 × 5个考核点，分数覆盖优秀到及格各层次 |

### 数据关联链路

