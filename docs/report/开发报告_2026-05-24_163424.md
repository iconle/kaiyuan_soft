## 问题

指标 3/7 的专业级达成度手工验算与系统值不符：指标 3 系统值 1.1437（手工 0.8241），指标 7 系统值 1.6506（手工 0.8253）。

## 根因

`GlobalCalcService.compute()` 构建权重记录时，同一课程的多班级各获完整宏观权重 W_c，未按班级数均分。

课程6（计算机网络）有两个教学班(3,4)，指标3的权重0.2原应各获0.1，实际各获0.2 → ΣW偏大1.4倍。

## 修复

构建权重记录前统计每门课程的班级数 `courseClassCount`，将宏观权重除以班级数后再分配给各班：

```java
// 统计每门课程班级数
Map<Long, Long> courseClassCount = new HashMap<>();
for (CourseStatus cs : dashboard.courseStatuses()) {
    courseClassCount.merge(cs.courseId(), 1L, Long::sum);
}
// 分配时按班级数均分
w = w.divide(BigDecimal.valueOf(classCount), 10, HALF_UP);
```

## 修改文件

`modulec/service/GlobalCalcService.java` — 新增班级数统计 + 权重均分
