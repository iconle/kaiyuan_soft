## 一、问题清单与修复

### Issue 1: 行政班级管理模块重构

**问题：** 原 ClassManage 使用 `teaching_class` 表，但需求是管理"行政班级"（如"计算机科学与技术2501班"），与教学班级是不同概念。

**修复：**
- 新建 `sys_admin_class` 表（major_id, class_name, enrollment_year）
- 新建 `admin_class_student` 表（admin_class_id, student_id）
- 新建实体：`SysAdminClass.java`, `AdminClassStudent.java`
- 新建 Mapper：`SysAdminClassMapper.java`, `AdminClassStudentMapper.java`
- DictService 新增 7 个行政班级方法
- DictController 端点路径改为 `/api/dict/admin-classes`
- ClassManage.vue 完全重写，面向行政班级
- SQL 脚本：`docs/database/seed_admin_class.sql`

### Issue 2: 教务管理员教学班级管理

**问题：** 教务管理员缺少独立的教学班级管理入口，无法指定主讲教师。

**修复：**
- 新建 `TeachingClassController.java`（`/api/teaching-classes`，ACADEMIC 角色）
- 新建 `TeachingClassManage.vue`（课程筛选 + 班级CRUD + 教师指派）
- 路由新增 `/academic/teaching-classes`
- 侧边栏新增「教学班级」菜单项（ACADEMIC 可见）
- `admin.js` 新增 7 个教学班级 API 函数

### Issue 3: 成绩解锁（勘误工单）前端入口

**问题：** 后端 `AdminScoreController` 已实现解锁，但前端无入口。

**修复：**
- `AdminScoreController` 新增 `GET /api/admin/scores` 列出所有成绩单及状态
- 新建 `ScoreUnlock.vue`（管理员查看已锁定成绩单，点击解锁）
- 路由新增 `/admin/score-unlock`
- 侧边栏新增「成绩解锁」菜单项（ADMIN 可见）

### Issue 4: 主讲教师多课程切换

**问题：** 所有教师登录后看到同一门课程（hardcoded classId=1），无法切换负责的多门课程。

**修复：**
- `TeachingClassController` 新增 `GET /api/teaching-classes/my-classes`（根据当前登录教师 ID 查询）
- `AdminLayout.vue` 侧边栏新增课程下拉选择器，onMounted 时自动加载教师班级列表
- 选择后存储到 localStorage，切换时导航到新课班的第一个页面
- 所有教师菜单项动态使用 `activeClassId`

### Issue 5: 数据溯源链路检查

**结论：** 已实现，前端有入口。

- 后端：`MajorReportService.generateTraceExcel()` → `TraceExcelExporter` 生成多 Sheet 穿透式台账
- 前端：`GlobalCompute.vue` → 专业级计算完成后显示"导出穿透式 Excel 台账"按钮
- 溯源路径：major_achievement → course_achievement → obj_achievement → assessment_point → student_score

### Issue 6: 课程级报表导出修复

**问题：** PDF/Excel 导出仍失败。

**根因：** `request.js` 拦截器对 `responseType: 'blob'` 的响应也尝试做 JSON 解包（`res.code` 检查），`blob.code` 为 undefined 导致误判失败。

**修复：**
- `request.js` 响应拦截器新增判断：`responseType === 'blob'` 时跳过 JSON 解包，直接返回 `response.data`
- 此前已修复 PdfExporter（字体降级）和 CourseReportService（Excel 填充明细）
