# Issue #262 个人达成度导出防重复提示

## 问题

教师端「个人达成度」页面导出 Excel 时，用户对导出过程感知不够明显，导出过程中可能重复点击按钮，或误以为系统没有响应。

## 优化

- 导出过程中按钮保持 loading 状态。
- 导出过程中按钮禁用，避免重复点击触发重复请求。
- 导出开始时提示“正在生成个人达成度 Excel，请稍候”。
- 导出过程中按钮文字显示为“生成中...”。
- 导出成功后提示文件已开始下载，并展示文件名。
- 导出失败时展示明确错误提示。

## 验证

1. 进入「个人达成度」页面，确保存在个人达成度数据。
2. 点击「导出 Excel」，按钮应进入 loading 状态并变为“生成中...”。
3. 导出过程中再次点击按钮，不应重复触发导出请求。
4. 导出开始时应显示生成中提示。
5. 导出成功后应提示文件已开始下载并显示文件名。
6. 网络异常时应显示导出失败提示。
