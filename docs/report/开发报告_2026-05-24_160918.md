## 问题

执行专业级计算提示"指标点 1 的权重总和为 0.2000，应等于 1.0"

## 根因

课程 2(高等数学B)、3(线性代数)、4(大学物理B) 无教学班级，无法产出课程级达成度。但它们的宏观矩阵权重仍在矩阵中，过滤后仅课程 1 的权重 0.2 参与计算，校验 Σ=1.0 失败。

## 修复

### 代码端

`GlobalCalcService.compute()` — 将硬性校验改为自动归一化：

```
计算每个指标点的 Σ W_c → 若 Σ ≠ 1.0 且 > 0，计算归一化因子 factor = 1/Σ
→ 每条有效权重 × factor → Σ = 1.0
```

无教学班的课程权重自动被排除，剩余权重按比例缩放至 1.0。

### 数据端

`cleanup_macro_matrix_orphans.sql` — 删除课程 2/3/4/7/8 的宏观矩阵条目（无教学班级），课程 1 在指标点 1 权重调整为 1.0。

```bash
mysql -u root -p < docs/database/cleanup_macro_matrix_orphans.sql
```
