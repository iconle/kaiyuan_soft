## Issue 1: 教务管理员教学班级无权限+无数据

**根因：** `SysUser` 实体只有 `roleId`（Long），前端 `TeachingClassManage.vue` 用 `u.roleCode === 'TEACHER'` 筛选教师列表，`roleCode` 从未被填充导致筛选结果始终为空。

**修复：**
- `SysUser.java` — 新增 `roleCode`/`roleName` 透传字段
- `UserService.java` — `listUsers` 批量查 `sys_role` 表，填充每个用户的 `roleCode` 和 `roleName`

## Issue 2: 专业负责人点击无权限菜单显示毕业要求界面

**根因：** 教务管理子菜单对 ACADEMIC 和 DIRECTOR 完全共享，DIRECTOR 点击「课程体系/学生名单/教学班级」被路由守卫重定向到其首页 `/director/grad-req`。

**修复：** 侧边栏添加角色可见性控制：

| 菜单项 | ACADEMIC | DIRECTOR |
|--------|:---:|:---:|
| 课程体系 | ✓ | ✗ |
| 学生名单 | ✓ | ✗ |
| 教学班级 | ✓ | ✗ |
| 宏观看板 | ✓ | ✓ |
| 成绩解锁 | ✓ | ✗ |

使用 `v-if="isAcademic"` 控制 ACADEMIC 专属菜单项，DIRECTOR 仅看到宏观看板。
