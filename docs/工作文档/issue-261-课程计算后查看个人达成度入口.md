# Issue #261 课程计算后查看个人达成度入口

## 问题

教师端「课程级计算」完成后会展示课程目标和指标点达成度，但用户如果想继续查看学生个人达成度，需要自行寻找入口，流程不够连贯。

## 优化

- 课程级计算完成并生成结果后，在完成提示区域显示「查看个人达成度」按钮。
- 课程级计算结果区顶部增加操作条，引导用户查看每位学生的个人达成度明细。
- 点击入口后跳转到当前教学班级的「个人达成度」页面。
- 未完成课程级计算或没有结果时不显示该入口。
- 入口在窄屏下保持可读，不挤压页面内容。

## 验证

1. 成绩未导入或未计算时进入「课程级计算」页面，不应显示「查看个人达成度」入口。
2. 完成「一键计算」后，页面应显示「查看个人达成度」按钮。
3. 点击按钮后，应跳转到当前教学班级的个人达成度页面。
4. 切换不同教学班级后，入口跳转路径应保持当前班级 ID。
