## 1. 需求概述

在系统管理模块的数据字典中增加"班级管理"功能，由系统管理员统一管理教学班级的 CRUD 及班级学生分配。此前教学班级的管理入口分散在教务管理员的课程管理下，此次调整后管理员可在数据字典模块集中管理班级基础数据。

## 3. 关键设计决策

1. **放置于 DictController**：班级属于基础数据字典范畴，与学院、专业、学期同层级管理，统一由管理员角色负责。与教务管理员的课程下班级管理（CourseController.listClasses）形成互补——管理员管理班级基础属性，教务管理员在课程上下文中管理班级。

2. **级联删除**：删除班级时自动清除 `class_student` 关联记录，避免孤儿数据。

3. **自动填充关联名称**：班级列表自动填充 `courseName` 和 `teacherName`（通过 `@TableField(exist = false)` 透传），减少前端二次查询。

4. **学生分配独立弹窗**：班级学生管理不嵌入班级编辑对话框，而是独立弹窗，支持搜索并添加学生、列表展示已分配学生、单个移除。
