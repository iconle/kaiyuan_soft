## 一、完成内容

### Issue 1: 行政班级-学生关系简化

**变更：** 删除 `admin_class_student` 关联表，在 `student` 表新增 `admin_class_id` 字段。

**理由：** 学生与行政班级是多对一关系（一个学生只属于一个行政班级），使用关联表属于过度设计。

**SQL 迁移脚本：** `docs/database/migrate_admin_class.sql`
```sql
ALTER TABLE student ADD COLUMN admin_class_id BIGINT;
-- 从 admin_class_student 迁移数据
UPDATE student SET admin_class_id = (...) WHERE EXISTS (...);
DROP TABLE admin_class_student;
```

**后端变更：**
- `Student.java` — 新增 `adminClassId` 字段
- `DictService.java` — `getAdminClassStudents/addAdminClassStudent/removeAdminClassStudent` 直接操作 `student.adminClassId`，不再使用关联表
- `StudentService.java` — `listStudents` 新增 `adminClassId` 筛选参数
- `StudentController.java` — list 端点新增 `adminClassId` 查询参数
- `AdminClassStudent.java` / `AdminClassStudentMapper.java` — 文件保留但不再使用

### Issue 5: 多角色成绩解锁入口

**需求依据：** SRS §5.3 — "如确需勘误，需向教务管理员提交工单，由管理员解锁"

**实现：**

| 角色 | 入口 | 操作 |
|------|------|------|
| ADMIN | 侧边栏「成绩解锁」 | 查看所有成绩单，解锁 |
| ACADEMIC | 侧边栏「成绩解锁」 | 同上（后端权限由 `hasRole('ADMIN')` 改为 `hasAnyRole('ADMIN','ACADEMIC')`） |
| TEACHER | CourseCompute 页面（成绩 LOCKED 时） | 显示勘误流程说明弹窗（4步骤引导），告知联系教务/系统管理员 |

**后端变更：**
- `AdminScoreController.unlockSheet` — 权限从 `ADMIN` 放宽到 `ADMIN+ACADEMIC`

**前端变更：**
- `CourseCompute.vue` — LOCKED 状态下显示勘误流程入口 + 步骤弹窗
- `router` — `score-unlock` 路由增加 `ACADEMIC` 角色
- `AdminLayout` — ACADEMIC 侧边栏新增「成绩解锁」菜单项
