## 问题

`Level1Calculator` 对同一考核点同时累加题目分和考核点分，导致 max 翻倍、达成度偏低。

## 根因

代码中 `else if` 分支对 `questionId=NULL` 的记录无条件累加，但此类记录（考核点级得分）在有题目存在时应被忽略：

```java
// 修复前：题目分 + 考核点分 都参与计算 → max 翻倍
if (questionId != null) { ... }       // 题目分
else if (relevantAssess) { ... }      // 考核点分（未排除已有题目的考核点）
```

## 修复

两趟扫描：先收集有题目覆盖的考核点，再累加时跳过这些考核点的考核点级记录。

```java
// 第一趟：收集哪些考核点已有题目得分
for (r) { if (r.questionId) questionedAssessments.add(r.assessmentId); }

// 第二趟：累加
if (questionId) { ... }                           // 题目分
else if (relevant && !questionedAssessments) { ... } // 仅无题目的考核点
```

确保：同一考核点的题目分和考核点分互斥，不重复累加。

## 修改文件

`engine/Level1Calculator.java` — 两趟扫描消除 double-count

## 影响

修复后需重新执行课程级计算，目标达成度将基于更准确的公式重新生成。
