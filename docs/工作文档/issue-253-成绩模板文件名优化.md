# Issue #253 成绩录入模板文件名优化

## 问题

教师端下载成绩录入模板时，文件名缺少教学班级上下文，多个班级模板保存到本地后不容易区分。

## 优化

- 下载文件名加入课程名称。
- 下载文件名加入教学班级名称。
- 下载文件名保留日期，便于识别模板下载时间。
- 如果班级信息尚未加载完成，使用教学班级 ID 作为兜底信息。

## 验证

1. 使用主讲教师账号登录系统。
2. 进入任一教学班级的「成绩导入」页面。
3. 选择考核点后点击「下载模板」。
4. 观察下载文件名，应符合「课程名-教学班级名-成绩录入模板-日期.xlsx」格式，例如：

```text
数据结构-数据结构-2025秋-1班-成绩录入模板-20260701.xlsx
```
