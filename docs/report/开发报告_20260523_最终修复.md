## Issue 4: 成绩勘误工单（三层操作流程）

**需求：** SRS §5.3 — 教师提交勘误申请 → 教务/管理员审批 → 解锁 → 教师修改重算

**数据库：** `docs/database/migrate_unlock_request.sql` — 新建 `score_unlock_request` 表

**后端新增：**
- `ScoreUnlockRequest.java` — 实体
- `ScoreUnlockRequestMapper.java` — Mapper
- `UnlockRequestService.java` — 核心业务：`submitRequest`/`listRequests`/`approveRequest`/`rejectRequest`
- `ScoreController` — 新增 `POST /api/classes/{classId}/request-unlock`（教师提交申请）
- `AdminScoreController` — 重写为 `GET /api/admin/unlock-requests` + `POST .../approve` + `POST .../reject`

**前端更新：**
- `CourseCompute.vue` — LOCKED 状态下显示「提交勘误申请」按钮 → 弹窗填写原因 → POST 提交
- `ScoreUnlock.vue` — 重写为工单审批界面：待审批/已批准/已拒绝三状态 + 批准/拒绝按钮

**三层流程：**

```
[1] 教师发现成绩有误
    → CourseCompute 页面 → 点击「提交勘误申请」
    → POST /api/classes/{classId}/request-unlock
    → score_unlock_request (status=PENDING)

[2] 教务/管理员审批
    → 侧边栏「成绩解锁」→ 勘误申请列表
    → 点击「批准解锁」→ POST /api/admin/unlock-requests/{id}/approve
    → score_sheet.status → IMPORTED（已解锁）
    → score_unlock_request (status=APPROVED)

[3] 教师修改成绩
    → ScoreImport 页面 → 成绩可编辑
    → 修改 → 重新触发课程级计算 → 重新锁定
```
