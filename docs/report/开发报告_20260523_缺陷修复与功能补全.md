## 一、缺陷修复（6项）

### Bug 1: ClassManage.vue 导入错误

**现象：** 点击班级管理无反应，控制台报 `does not provide an export named 'listCourses'`

**根因：** `ClassManage.vue:93` 从 `admin.js` 导入 `listCourses`，但该函数定义在 `academic.js`

**修复：** `frontend/src/views/admin/ClassManage.vue`
- 将 `listCourses` 从 `admin.js` 导入改为从 `academic.js` 导入

### Bug 2: 宏观看板选择专业后无数据

**现象：** 教务管理员/专业负责人进入宏观看板，选择专业后表格无数据显示

**根因1：** `GlobalDashboard.vue` 调用 `listMajors()` 返回的是 `PageResult` 对象（`{ records: [...], total: N }`），但前端误作数组使用 `res.data || []`，导致下拉框无可选项

**根因2：** `GlobalDashboard.vue` 错误处理为静默 `catch { /* handled */ }`，后端异常时用户无感知

**修复：**
- `GlobalDashboard.vue`: `majors.value = res.data?.records || []`
- `GlobalDashboard.vue`: 新增空状态提示（totalCount=0 时显示引导文字）

### Bug 3: 专业负责人无权限访问专业级计算

**现象：** director01 账号点击专业级计算显示无权限

**根因：** `GlobalCompute.vue` 调用 `listSemesters()` 获取学期列表，但后端 `GET /api/dict/semesters` 需要 `@PreAuthorize("hasRole('ADMIN')")`，DIRECTOR 角色被 403 拒绝，且前端静默吞错导致页面卡死

**修复：**
- `DictController.java`: 学期列表端点权限从 `hasRole('ADMIN')` 放宽为 `hasAnyRole('ADMIN','ACADEMIC','DIRECTOR','TEACHER')`（学期为只读字典数据，所有角色均可读取）
- `GlobalCompute.vue`: `majors.value = mRes.data?.records || []`

### Bug 4: 无权限模块点击后无任何提示

**现象：** director01 点击"课程体系""学生名单"等无权限菜单，页面无任何反应（实际被路由守卫静默重定向到首页）

**根因：** `router/index.js` 行147-149，角色不匹配时直接 `next(home)` 跳转，无用户提示

**修复：**
- `router/index.js`: 重定向前将目标路径写入 `sessionStorage('permDenied')`
- `AdminLayout.vue`: `onMounted` 中检测 `permDenied` 标志，弹出 `ElMessage.warning('无权访问「xxx」，已跳转到您的首页')`

### Bug 5: 成绩导入模板下载失败

**现象：** 教师点击"下载成绩模板"提示"请求失败"

**根因：** `ExcelTemplateService.java:95` 使用 `WorkbookFactory.create(true)` 创建 XLSX 工作簿，但该 API 在 EasyExcel 3.3.4 依赖的 POI 版本中行为不稳定

**修复：** `ExcelTemplateService.java`
- 替换为 `new XSSFWorkbook()` 直接实例化

### Bug 6: 课程级计算报表导出失败

**现象：** 点击"导出PDF报告"和"导出Excel报告"均提示"请求失败"

**根因1（PDF）：** `PdfExporter.java` 硬编码加载中文字体文件 `/fonts/NotoSansSC-Regular.ttf`，文件不存在时传入 null 导致 NPE

**根因2（Excel）：** `CourseReportService.generateExcel()` 生成空 `TraceRow` 列表，无实际数据

**修复：**
- `PdfExporter.java`: 重写字体加载逻辑，依次尝试 3 种中文字体路径，全部失败时降级为 PDFBox 内置 Helvetica 字体（英文输出），不再抛异常；同时简化输出逻辑为 `writeLine()` 辅助方法
- `CourseReportService.generateExcel()`: 从 `ScoreService.getScorePreview()` 提取考核点平均分，生成含实际数据的明细行

## 二、缺失功能补全（2项）

### 功能1: 专业级计算（阶段二）事务流程

**对应文档：** 系统架构设计 §3.4.2

**实现状态：** 第3周已实现 `GlobalCalcService.compute()` 及 `GlobalCalcController`，本次修复了前端调用链中的权限和数据加载问题（见 Bug 2/3），确保端到端可工作。

**流程：**
```
专业负责人点击"执行专业级计算"
  → GET /api/global/dashboard (前置校验：检查所有课程已锁定)
  → POST /api/global/compute (Level3 计算 → 持久化 major_achievement)
  → GET /api/reports/major/radar (雷达图数据)
  → GET /api/reports/major/excel (穿透式台账)
```

### 功能2: 成绩解锁（勘误工单）流程

**对应文档：** 系统架构设计 §3.4.3

**实现状态：** 第3周已实现 `AdminScoreController.unlockSheet()` 及 `CourseCalcService.unlockSheet()`。本次修复删除了 `ScoreService` 中不完整的重复 `unlockSheet()` 方法（该版本仅改状态不删计算结果），确保解锁流程的完整性。

**流程：**
```
教务管理员调用 POST /api/admin/scores/{sheetId}/unlock
  → 校验权限 (hasRole('ADMIN'))
  → 校验成绩单状态为 LOCKED
  → DELETE obj_achievement (清除目标级结果)
  → DELETE course_achievement (清除课程级结果)
  → UPDATE score_sheet SET status='IMPORTED', locked_at=NULL, locked_by=NULL
  → 以上操作在同一事务中完成
```

**前端支持：**
- `admin.js` 已导出 `unlockScoreSheet(sheetId)` 函数
- 管理员可在成绩管理界面调用解锁
- 解锁后教师可重新修改成绩并重新触发阶段一计算
