### 3.4 认证流程

1. 用户提交用户名/密码到 `POST /api/auth/login`
2. 后端通过 BCrypt 校验密码，查询 `sys_role` 获取角色信息
3. 生成 JWT Token（包含 userId、username、roleCode、realName）
4. 前端存储 Token 到 localStorage，后续请求通过 `Authorization: Bearer <token>` 携带
5. `JwtAuthFilter` 解析 Token，设置 Spring Security 上下文
6. 接口通过 `@PreAuthorize("hasRole('ADMIN')")` 进行角色鉴权

### 3.5 配置说明

- **application-dev.yml**：MySQL 连接 `localhost:3306/obe_platform`，默认账号 `root/root`
- **JWT 密钥**：默认值在 `application.yml` 中配置，生产环境通过环境变量 `JWT_SECRET` 覆盖
- **默认管理员**：用户名 `admin`，密码 `admin123`（首次登录后请修改）

| 路径 | 组件 | 权限 |
|------|------|------|
| `/login` | LoginView | 公开 |
| `/admin/users` | UserManage | ADMIN |
| `/admin/dict` | DictManage | ADMIN |

路由守卫：未登录重定向到 `/login`，无权限拒绝访问。

### 4.4 已实现功能

- **登录页**：用户名/密码表单，支持回车提交，JWT Token 存储
- **用户管理页**：分页列表、关键词搜索、角色筛选、新增/编辑/禁用/重置密码
- **数据字典页**：三个 Tab 页（学院/专业/学期），每个 Tab 支持 CRUD 操作
- **管理后台布局**：左侧导航 + 顶栏（显示用户信息和退出按钮）
- **Axios 拦截器**：自动注入 Token，401 自动跳转登录页
