## 计算逻辑

```
对于目标 j：
  ├── 有题目的考核点 → 用题目得分 / 题目满分（细粒度）
  └── 无题目的考核点 → 用考核点得分 / 考核点满分（原逻辑）
C_ij = Σ(相关得分) / Σ(相关满分)
```
