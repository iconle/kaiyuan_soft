## 问题

管理员能看到 PENDING 状态的勘误申请，但这些申请尚在教务审核阶段，管理员不应看到。

## 修复

`UnlockRequestService.listRequestsForRole()` — 根据角色过滤：

| 角色 | 可见状态 |
|------|---------|
| ACADEMIC（教务） | PENDING / APPROVED / REJECTED / UNLOCKED（全部） |
| ADMIN（管理员） | APPROVED / REJECTED / UNLOCKED（排除 PENDING） |

教务审核阶段的 PENDING 工单对管理员完全不可见，只有教务同意后（APPROVED）管理员才能在列表中看到并决定解锁。

## 修改文件

| 文件 | 变更 |
|------|------|
| `UnlockRequestService.java` | `listRequests()` → `listRequestsForRole(roleCode)`，ADMIN 角色过滤 `status != 'PENDING'` |
| `AdminScoreController.java` | `listRequests()` 传入 `currentRoleCode()` |
