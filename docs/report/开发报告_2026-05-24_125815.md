## 问题

进入成绩导入模块提示：`Null key for a Map not allowed in JSON`

## 根因

`ScoreService.getScorePreview()` 使用 `Map<Long, BigDecimal>` 存储题目成绩，key 为 `questionId`。当成绩为考核点级（无题目）时 `questionId = null`，Jackson 无法序列化 null 键的 Map。

## 修复

改为 `List<StudentScore>` 分组后遍历：
- `questionId == null` → 存入 `ScoreCell.score`（考核点级成绩）
- `questionId != null` → 存入 `ScoreCell.questionScores`（题目级成绩，Map 键均为非 null）

## 修改文件

`modulec/service/ScoreService.java` — 重构分组逻辑，消除 null key
