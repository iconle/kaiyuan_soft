## 问题

教务管理员（academic01）点击教学班级菜单，页面加载后 API 调用返回 403 "无权限访问"，数据无法显示。

## 根因

`UserController` 类上声明了 `@PreAuthorize("hasRole('ADMIN')")`，导致该控制器所有端点（包括 `GET /api/admin/users`）仅 ADMIN 可访问。

TeachingClassManage.vue 在 `onMounted` 中调用 `listUsers()` → `GET /api/admin/users` → Spring Security 拦截 → 403 → axios 拦截器显示 "无权限访问"。

## 修复

移除类级别 `@PreAuthorize`，改为方法级别精确控制：

| 端点 | 权限 |
|------|------|
| GET /api/admin/users | `hasAnyRole('ADMIN','ACADEMIC')` — 教务需拉取教师列表 |
| GET /api/admin/users/{id} | `hasRole('ADMIN')` |
| POST /api/admin/users | `hasRole('ADMIN')` |
| PUT /api/admin/users/{id} | `hasRole('ADMIN')` |
| DELETE /api/admin/users/{id} | `hasRole('ADMIN')` |
| PUT /.../reset-password | `hasRole('ADMIN')` |
| GET /api/admin/users/roles | 无需权限（已登录即可） |

## 修改文件

`UserController.java` — 类级别 `@PreAuthorize` 移除，各方法加独立注解，list 端点开放给 ACADEMIC。
